Sabor — Restaurant & Café HTML Template

Documentation · Version 1.0 · Pure HTML5 / CSS3 / Vanilla JavaScript — no frameworks, no build step, no external dependencies.

2. Installation

  1. Unzip the package.
  2. Upload the whole sabor-html-template folder to your web host (or open index.html locally in a browser — everything works without a server).
  3. Done. There is no build step and nothing to compile.

Note: The reservation form validates on the client side and shows a confirmation message, but it does not send email by itself. Connect it to your booking system or a form service by pointing the form's submit handler (see js/form.js) to your endpoint.

3. Customising

3.1 Colours & dark mode

All colours live in CSS variables at the top of css/style.css. Change --accent (terracotta) and --gold to rebrand the whole site. Dark-mode values are in the [data-theme="dark"] block right below. The toggle button in the header switches themes and remembers the visitor's choice in localStorage.

3.2 Text & content

Every text is plain HTML — edit it directly in the page files. The header, footer and navigation are repeated in each page (standard for static templates), so update them in all five files when you change links or contact details.

3.3 Images

Demo photos are in assets/img/. Replace them with your own photos using the same file names to avoid touching any HTML:

FileUsed for
hero-dish.jpgHome hero background + salmon dish card + gallery
dish-pasta.jpgPasta dish card + gallery
dish-dessert.jpgDessert dish card + gallery
interior.jpgHome & About story sections + gallery

The gallery also includes CSS “art tiles” — gradient placeholders with an icon and text. Replace a tile with a photo by swapping the .art-tile block for an <img> tag (example in the gallery page comments).

3.4 Menu items

Menu categories are panels in menu.html. Each tab button has a data-target matching a panel id (panel-starters, panel-mains, panel-desserts, panel-drinks). To add a category: copy a button, change its label and data-target, then copy a panel with the matching id and edit the dishes.

3.5 Testimonials

Add or remove .testimonial-slide blocks in index.html — the slider dots and auto-rotation adjust automatically.

3.6 Reservation form rules

Validation lives in js/form.js: required fields, email format, phone (7+ digits), no past dates, and 1–20 guests. Edit those rules in one place if your restaurant differs.

4. Browser support

Current versions of Chrome, Firefox, Safari and Edge. Uses CSS variables, flexbox, grid and IntersectionObserver — with graceful fallbacks (content stays visible if an API is missing).
