SABOR — Restaurant & Café HTML Template · v1.0
================================================================

A warm, fully responsive HTML5/CSS3/JS template for restaurants,
cafés, bistros and bakeries. No frameworks, no build step, no
external dependencies — it works offline and on any static host.

PAGES
  index.html ......... Home (hero, featured dishes, testimonials)
  menu.html .......... Menu with category tabs
  about.html ......... Story, values, team
  gallery.html ....... Gallery with lightbox
  reservation.html ... Reservation form + contact info

FEATURES
  * Dark / light mode toggle (saved per visitor)
  * Mobile navigation + fully responsive layout
  * Scroll-reveal animations
  * Auto-rotating testimonials slider
  * Client-side form validation
  * Buyer documentation included (documentation.html)

QUICK START
  1. Unzip. 2. Upload the folder to your host (or open index.html).
  3. Replace the demo photos in assets/img/ with your own.
  Full guide: documentation.html
